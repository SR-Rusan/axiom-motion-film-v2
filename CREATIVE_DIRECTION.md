# AXIOM BY RUSAN // V2 MOTION IDENTITY FILM

## Live-site read

The live website presents Axiom as a founder-led engineering studio rather than a generic AI agency. Its strongest ideas are:

- **From Bottleneck to System** — the core transformation.
- **I build practical AI automations that eliminate repetitive work, connect your tools, and give growing businesses more time to focus on what actually matters.**
- **Direct Advisory with Rusan** — no account managers or telephone games.
- **AI automation for growing businesses** and **AI Consultancy & Digital Growth**.
- Existing workflows stay in the client’s tools and accounts; the work is structured, private, documented, and measurable.
- The site’s product-like language includes **Axiom Core**, **Automation Overview**, **New automation**, **Systems Operational**, and **Your automation systems are running smoothly.**

## Visual system extracted from the live site

- Canvas: white, near-white, and very soft neutral panels.
- Ink: deep charcoal / blue-black, approximately `#25292D`.
- Accent: electric indigo, approximately `#635BFF` / HSL 239 84% 67%.
- Status: emerald `#10B981`.
- Borders: thin neutral rules around cards and input-like modules.
- Type: Instrument Serif for editorial emphasis; Inter for interface and body copy.
- UI language: compact mono labels, small status dots, dashboard chrome, thin graphs, understated shadows, moderate corner radius.
- Motion language: product-like state changes, not spectacle; cards and data resolve into a composed system.

## Single idea

**Make the invisible operating layer legible.**

The viewer sees the hidden work behind a growing business become a readable, connected workflow. Axiom does not add more noise; it gives existing tools a system.

## New shot list and copy

### 00:00–00:02 — The hidden layer

- Copy: `THE WORK BEHIND THE WORK`
- Secondary: `hidden friction / visible signal`
- Visual: an editorial baseline, a blinking input caret, and a single indigo trace reveal the words. The baseline becomes the first workflow rail.

### 00:02–00:04.5 — The bottleneck

- Copy: `EVERY DAY HAS A DRAG LAYER.`
- Visual: form, inbox, spreadsheet, and CRM fragments arrive as pale interface tiles. They repeat and drift out of phase; the same request is shown as four disconnected states.

### 00:04.5–00:07 — Intelligence organizes

- Copy: `MAKE IT LEGIBLE.`
- Secondary: `INPUT / CONTEXT / ACTION`
- Visual: the tiles reduce to a single measured rail. Indigo nodes connect; a crosshair scans the line; each state receives a precise green confirmation.

### 00:07–00:10.5 — Axiom Core

- Copy: `Axiom Core`
- UI copy: `Automation Overview`, `New inquiry submitted on website form`, `Autonomous Lead Qualification & CRM Sync`, `SYSTEMS OPERATIONAL`
- Visual: a living interface, not a screenshot. A graph draws, counters tick, the inquiry packet travels through context into a CRM action, and the status changes.

### 00:10.5–00:13 — The transformation

- Copy: `FROM BOTTLENECK` → `TO SYSTEM`
- Secondary: `Custom automations delivered in 7–14 days.`
- Visual: the dashboard folds into a typographic comparison. The arrow is made from the same line that carried the inquiry packet.

### 00:13–00:15 — The brand memory

- Copy: `AXIOM` / `by Rusan`
- Secondary: `AI automation for growing businesses`
- CTA: `Request 20-Min Discovery Session`
- Status: `SYSTEMS OPERATIONAL`
- Visual: the indigo trace resolves into the site’s four-point sparkle. Quiet, centered, readable hold.

## Motion rules

- Interface modules move quickly and precisely.
- Editorial type lands with weight and a restrained 2–4px overshoot.
- The workflow trace is the continuity device across all six beats.
- The most saturated indigo moment is the system lock and brand sparkle.
- No generic fades, stock imagery, invented product claims, or random particles.
